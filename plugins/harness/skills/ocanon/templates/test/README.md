# 시험 자산 색인 — {{PROJECT}}

> 상태: 작성 중 · 최종 갱신일: {{DATE}}
> 역할: 다시 돌릴 수 있는 시험 자산(스크립트·시나리오·픽스처·기대값·판정 규칙·재현 스크립트)의 단일 색인이다.
> 진입: `plan/index.json` 의 `assets.test_root` 가 이 파일을 가리킨다.

## 원칙
- 필요한 것만 만든다. 아래 계층은 쓸 일이 생겼을 때 그 폴더만 만든다(빈 골격을 미리 만들지 않는다).
- 남기기 전에 보존 판정을 1회 한다: K4(비중복) ∧ K5(안전·크기) ∧ (K1 재실행 ∨ K2 재생성 비용 ∨ K3 근거성). 색인의 "재사용 이유" 칸에 K 번호와 한 줄 이유를 적는다. 빈 칸은 감사 경고 대상이다.
- 같은 도구를 판 사본(`_v1`·`_v2`·`_r2`·`_old`·`_bak`·`_copy`)으로 늘리지 않는다. 기존 파일을 고치고 최종판 1개만 둔다.

## 계층
| 경로 | 담는 것 |
|---|---|
| `common/` | 축 공통 헬퍼(대기·재시도·증거 저장 경로 계산 등) |
| `<축>/measure/` | 측정 스크립트(수치를 뽑는다). 축 예: desktop·web·mobile·api·perf |
| `<축>/judge/` | 판정 스크립트·판정 규칙(`rules_*.md`). 측정 결과를 기준과 대조한다 |
| `<축>/record/` | 기록·수집 스크립트(로그·스크린샷을 결과 위치로 모은다) |
| `testdata/` | 고정 시험 자료·픽스처·기대값·작은 스냅샷(텍스트·작은 이미지) |
| `repro/` | 회귀 가치가 있는 버그 재현 스크립트(관련 버그·커밋을 색인에 적는다) |
| `archive/` | 다른 도구로 대체된 자산(이름·내용 불변으로 옮긴다) |

## 도구 색인
| 경로 | 용도 | 재사용 이유(K) | 실행 명령 | 관련 REQ/TC | 마지막 사용 | 상태 |
|---|---|---|---|---|---|---|
| (예시) `web/judge/judge_login.py` | 로그인 화면 판정 | K1 회귀 시험마다 재실행 | `python3 -B test/web/judge/judge_login.py --input <결과 경로>` | REQ-01 / TC-003 | {{DATE}} | 사용 |

상태 값은 `사용`·`대체됨→<새 경로>`·`보관(archive/…)` 중 하나다. "대체됨" 행은 다음 정리 때 `archive/` 로 옮긴다. 180일 넘게 쓰지 않았고 대체 도구가 있으면 정리 후보다.

## 안전 규칙
- 결과 데이터(회차 로그·스크린샷·측정 원시값)는 `test/` 에 쓰지 않는다. 세션 로그나 archive 로 보낸다. 시험결과서에는 요약과 증거 위치만 남긴다.
- 판정 규칙(`rules_*.md`·기대값)은 결과를 보기 전에 고정한다. 결과를 본 뒤 기준을 바꾸려면 새 규칙 판으로 고치고 바꾼 이유를 결정기록(ADR)에 남긴다.
- 실계정·토큰·비밀번호·실서버 주소·포트를 파일에 적지 않는다. 환경변수나 INFRA 문서 참조로만 받는다.
- 1회성 탐침 스크립트는 남기지 않는다.
- 생성물(`__pycache__`·`*.pyc`·빌드 결과)과 1MB 넘는 바이너리는 두지 않는다.
