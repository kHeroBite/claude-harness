# odev_impact — 영향도 분석

## 목적

구현 완료 후, 변경된 심볼/인터페이스의 **참조를 자동 추적**하여 누락된 수정 지점을 감지합니다.

## 활성화 조건

```yaml
필수:
  - 인터페이스/메서드 시그니처 변경 포함 시
  - 공통모듈(Shared) 변경 포함 시
  - 크로스 레이어 변경 시 (DB→Backend→Frontend)

불필요:
  - UI 전용 변경 (단일 폼 내부 수정)
  - 문서/설정 파일만 변경
  - 기존 인터페이스 내 구현 변경
```

## 에이전트 유형

```yaml
유형: Explore (읽기 전용, Serena 심볼 탐색 활용)
모델: Sonnet (참조 추적은 분석력 필요)
제약: 파일 수정 절대 금지 — 분석/보고만
```

## 분석 범위

```yaml
심볼_참조_추적:
  도구: Serena find_referencing_symbols
  대상: 시그니처가 변경된 메서드/클래스/인터페이스
  결과: 해당 심볼을 참조하는 모든 코드 위치

쿼리_참조_추적:
  대상: 변경/삭제/이름변경된 쿼리 (공유 라이브러리 Queries/)
  방법: Grep으로 쿼리명 참조 검색
  결과: 호출부가 새 시그니처에 맞게 수정되었는지 확인

DB_스키마_영향:
  대상: 테이블/컬럼 변경 시
  방법: 해당 테이블을 참조하는 쿼리 추적
  결과: 쿼리와 코드가 새 스키마에 맞게 수정되었는지 확인
자매_함수_대칭_점검 (L-977 — 2026-09-07 사이클88 D-7/D-9/D-13 공통 원인):
  대상: 수정 대상 함수와 동일 역할의 형제 — 접미사(WithRow/View/Init/Load), 축 대칭(프로젝트↔티켓↔작업), 초기화 짝(초기화↔Load)
  방법: 수정 함수명의 어간으로 Grep → 형제 목록 확보 → 같은 수정이 필요한지 하나씩 판정
  결과: 양쪽 모두 적용했거나, 달라야 하는 이유가 주석으로 남았는지 확인 (한쪽만 고친 채 완료 보고 금지)
```

## 실행 절차

```yaml
1_리더가_Impact_디스패치:
  시점: 모든 구현 에이전트 완료 후 (코드 리뷰와 병렬)
  방법: Task(Explore) 서브에이전트 생성 (v3.2 flat team — TeamCreate 금지)
  프롬프트: |
    아래 변경사항의 영향도를 분석하라:

    [변경된 심볼/메서드 목록]
    [변경 유형: 시그니처/이름/삭제/추가]

    Serena find_referencing_symbols로 각 심볼의 참조를 추적하고,
    참조하는 코드가 새 시그니처에 맞게 수정되었는지 확인하라.

    결과 파일: {scratchpad}/impact_report.md
    반환: 누락 수 + 요약 5줄 + 파일 경로

2_코드_리뷰와_병렬_실행:
  둘 다 읽기 전용이므로 충돌 없음

3_결과_처리:
  누락_없음: otest 단계로 진행
  누락_발견: 리더가 추가 수정 → 재빌드 → 재분석 (최대 1회)

4_신설_public_메서드_호출부_대조 (종료 전 체크 1항, 2026-09-15 사이클131/132 L-1065):
  배경: 사이클132g 가 공지 실시간 푸시의 수신 경로(GW → 클라 브로드캐스트 → 구독 콜백)를
        완성했으나 그 경로를 호출하는 코드가 0건이라 기능이 전혀 발화하지 않았다.
        수신측 완성만으로 "만들었다"고 끝내면 조용한 미발화가 남는다.
  방법: 이번 작업에서 신설한 public 메서드 목록 ↔ grep 전수로 호출부 대조.
  판정: 호출부 0건이면 ⓐ의도된 라이브러리 API(리플렉션/이벤트 핸들러/인터페이스 구현 등)
        ⓑ트리거 누락 중 무엇인지 ★명시 기재★한다. 판정을 자동으로 내리지 않고 사람(리더)이
        확인하게 남긴다 — 이름 규약(Broadcast/Push/Notify 등)만으로는 신규/기존을 가를 수
        없어 물리 차단은 오탐 위험이 크다(실측: 게이트웨이+공유 모듈 public 567개 중 48개
        8.5%가 정당한 무호출).
  금지: 대조 자체를 생략 (판정은 사람이 하되, 대조는 생략 불가)
```

## 결과 형식

```markdown
# 영향도 분석 보고서

## 판정: ✅ 누락 없음 / ⚠️ 누락 N건 발견

## 변경 심볼별 참조 현황
| 변경 심볼 | 변경 유형 | 참조 수 | 수정 완료 | 미수정 | 상태 |
|----------|----------|---------|----------|--------|------|

## 미수정 참조 상세 (누락 발견 시)
- [파일:라인] — [참조 코드] — [필요한 수정]

## 크로스 레이어 영향
- [영향 경로: 공유 라이브러리 → 참조 프로젝트 전체]
```

## 제한사항

```yaml
읽기_전용: 파일 수정 절대 금지 (누락 발견 시 보고만)
scratchpad_필수: 결과를 반환 메시지에 전체 포함 금지
심볼_추적_제한: 변경된 심볼 최대 20개 (초과 시 리더에게 분할 요청)
```
