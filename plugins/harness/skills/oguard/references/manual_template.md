# <가드 이름> <수정 요지> 매뉴얼

> oguard 가 codex 에 넘기는 실행 매뉴얼이다. 6개 절의 제목을 바꾸지 않는다(스크립트가 제목으로 검사한다).

## 목적

- 무엇을 왜 바꾸는가(과차단 사례 원문 또는 해제 사유).
- 바꾼 뒤 기대 동작(허용돼야 할 사례, 계속 차단돼야 할 사례).

## 대상 파일

- `/절대경로/대상1.sh`
- `/절대경로/tests/test_대상1.sh`

## 변경 내용

1. `/절대경로/대상1.sh` 에서 아래 원문을 정확히 1건 찾아 교체한다. 0건이거나 2건 이상이면 멈추고 보고한다.

   전:
   ```bash
   (원문 그대로)
   ```

   후:
   ```bash
   (바꿀 내용 그대로)
   ```

2. (필요하면) 패치 스크립트. 본문은 매뉴얼 옆 별도 파일(`<매뉴얼 이름>.patch.py`)에 두고 여기에는 실행 한 줄만 적는다(인라인 heredoc 금지 — 셸 변환으로 깨진다). 치환 후 남아서는 안 되는 문자열을 검사하고, 남으면 중단하게 쓴다.

   ```bash
   python3 -B /절대경로/<매뉴얼 이름>.patch.py
   ```

## 검증

- `bash -n /절대경로/대상1.sh` → 출력 없음, rc=0
- `python3 -c "import sys;compile(open(sys.argv[1]).read(),sys.argv[1],'exec')" /절대경로/대상1.py` → 출력 없음, rc=0
- 파이썬 문법 검증에 py_compile 사용 금지 — .pyc 생성이 codex 의 대상 밖 파일 생성 금지와 충돌해 멈춘다(L-1486).
- `grep -c '<지운 식별자>' /절대경로/대상1.sh` → 0
- `bash /절대경로/tests/test_대상1.sh` → `FAIL=0`
- 허용·차단 사례 표(입력 → 기대 결과)
